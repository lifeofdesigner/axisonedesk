# Configuration Files

| File | Purpose |
|---|---|
| `vite.config.ts` | Vite build config |
| `tsconfig.json` / `tsconfig.app.json` / `tsconfig.node.json` | TypeScript project references |
| `eslint.config.js` | ESLint flat config (typescript-eslint) |
| `.prettierrc` | Prettier + `prettier-plugin-tailwindcss` |
| `components.json` | shadcn/ui component generation config |
| `vercel.json` | Vercel deploy — SPA rewrite only |
| `supabase/config.toml` | Supabase CLI project link/config |
| `.env.example` | Env var names — see [ENVIRONMENT_VARIABLES.md](ENVIRONMENT_VARIABLES.md) |
| `package.json` | Dependencies + scripts — see [BUILD_SCRIPTS.md](BUILD_SCRIPTS.md), [DEPENDENCIES.md](DEPENDENCIES.md) |

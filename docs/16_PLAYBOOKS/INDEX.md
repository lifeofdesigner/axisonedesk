# 16_PLAYBOOKS

Recurring-task playbooks for day-to-day engineering work on AxisOneDesk — distinct from `.ai/` (which covers building not-yet-built architectural systems like the Industry Engine). Read [_GENERIC_CREATE_WORKFLOW.md](_GENERIC_CREATE_WORKFLOW.md) first — every `CREATE_*` playbook below is a short delta on top of it, not a standalone repeat, per the no-duplication rule in [docs/00_ADOS/AI_INSTRUCTIONS.md](../00_ADOS/AI_INSTRUCTIONS.md).

Every playbook follows: Purpose, Prerequisites, Required Documentation, Audit Steps, Implementation Workflow, Validation, Testing, Documentation Updates, Definition of Done, Commit Requirements.

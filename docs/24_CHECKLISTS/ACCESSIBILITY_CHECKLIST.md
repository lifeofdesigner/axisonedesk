# ACCESSIBILITY_CHECKLIST

See [21_GOVERNANCE/ACCESSIBILITY_STANDARDS.md](../21_GOVERNANCE/ACCESSIBILITY_STANDARDS.md).

- [ ] Keyboard-navigable (tab order, Esc closes dialogs)
- [ ] Form fields have associated labels
- [ ] Color contrast checked in both light and dark theme
- [ ] Icons used alone have `aria-label`
- [ ] No functionality relies on hover alone (mobile has no hover)

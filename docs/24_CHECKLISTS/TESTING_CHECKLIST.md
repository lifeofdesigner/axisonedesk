# TESTING_CHECKLIST

See [docs/11_TESTING/INDEX.md](../11_TESTING/INDEX.md) — no framework exists yet, so this checklist is manual-verification-focused until one is adopted.

- [ ] Golden path manually exercised in browser
- [ ] At least one edge case manually exercised (empty state, invalid input, permission-denied)
- [ ] If a test suite exists for this area by the time you're reading this: automated tests pass
- [ ] If it should be tested and can't be yet: gap logged in [docs/00_ADOS/TECHNICAL_DEBT.md](../00_ADOS/TECHNICAL_DEBT.md)

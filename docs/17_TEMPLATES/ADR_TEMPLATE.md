# ADR_TEMPLATE

Matches the format used in [docs/00_ADOS/DECISIONS.md](../00_ADOS/DECISIONS.md) — append new ADRs there, don't create standalone ADR files.

```markdown
## ADR-0NN — YYYY-MM-DD: <short decision title>

**Context**: <the problem/situation that forced a decision>

**Decision**: <what was decided, stated plainly>

**Consequences**: <what this makes easier, harder, or forecloses>
```
